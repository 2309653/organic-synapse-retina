# 人工视网膜仿真：感知-存储-识别一体（不训练神经网络）

复现 **Nature Photonics 2023**（[Chen et al., "Organic optoelectronic synapse based on
photon-modulated electrochemical doping"](https://www.nature.com/articles/s41566-023-01232-x)）
里"人工视网膜、无需复杂人工神经网络做识别"的应用思想：

```
图像亮度 → 光脉冲个数（越亮脉冲越多）→ 器件电导就地存储 → 与注册模板比对 → 识别
```

器件既是**探测器**又是**存储器**，没有梯度训练、没有反向传播。这是与姊妹仓库
[organic-synapse-mnist](https://github.com/2309653/organic-synapse-mnist)
（用器件电导当权重、训练 MLP 做 MNIST）完全不同的第二条应用路线。

## 结果速览（MNIST，CPU 秒级）

| 配置 | 模板匹配识别精度 |
|---|---|
| 基线（读噪声 0.15，n_max=30） | **71.0%** |
| 器件衰减 60% 后再读出 | 68.8% |
| 像素间电导窗口偏差 ±30% | 69.2% |
| 光脉冲分辨率 n_max 从 5 到 100 | 基本不变（~71%） |

对照：训练型 MLP（姊妹仓库）96.4%。**"感知即计算"的视网膜精度低但省掉了整个
训练和推理算力链路**——这正是两类应用的本质取舍。曲线图见
`figures/fig2_retina_sweep.png`（分辨率/衰减/一致性三联图）。

三个物理结论（都能在上面的扫描里看到）：
1. **衰减（保持特性）伤识别**：图像在等待比对期间"变淡"，信噪比下降；
2. **像素间一致性伤识别**：每个单元电导窗口有固定偏差，感存图被扭曲
   （文献里 "high-uniformity array" 强调的就是这个指标）；
3. **分辨率对 MNIST 几乎不重要**：手写数字接近二值（黑/白），几档电导就够；
   换成灰度层次丰富的人脸（原文的应用），分辨率才会成为关键。

## 运行

```bash
pip install -r requirements.txt

python src/retina.py                 # 单次运行 + 流程图
python src/retina.py --sweep         # 三因素扫描 + CSV
python src/retina.py --dataset fashion   # Fashion-MNIST（见下方下载说明）
```

常用参数：`--n-max`（光脉冲上限=分辨率）、`--decay`（读出前衰减 0~1）、
`--read-noise`（读噪声 σ，窗口比例）、`--cell-variation`（像素间窗口偏差 σ）、
`--calib`（每类注册模板样本数）、`--test`（测试图数量）。

Fashion-MNIST 下载慢时，从 http://fashion-mnist.s3-website.eu-central-1.amazonaws.com/
手动下载 4 个 .gz 放入 `data/FashionMNIST/raw/`。

# 通用测试方法步骤（器件 → 任何应用，都走这六步）

不管最终做哪条应用路线，对器件本身的测试流程是同一套：

### 第 1 步：单脉冲响应（EPSC）
施加一个光/电脉冲，记录电导随时间的响应曲线。目的：确定读电压（小到不扰动状态）、
响应幅度、响应时间。这是所有后续测量的"读出协议"。

### 第 2 步：塑性表征（STP / LTP / PPF）
- 短期可塑性 STP：单脉冲后电导先升后弛豫回落的分量；
- 长期可塑性 LTP：多次刺激后留下的不回复分量；
- 双脉冲易化 PPF：第二个脉冲的响应比第一个大（间隔越短越明显），用
  PPF 指数 = (A2−A1)/A1×100% 对脉冲间隔作图。
目的：证明器件确实"像突触"，这是突触器件论文的基本盘。

### 第 3 步：增强/抑制曲线 G(n)（核心测量）
- 先擦到电导底 → 施加 N 个**完全相同**的增强脉冲，每两个脉冲间插一个读脉冲 → G_p(n)；
- 再从电导顶 → N 个抑制脉冲 → G_d(n)；
- 每条曲线**重复 ≥10 个循环**（看循环间涨落），最好多测几个器件（看器件间差异）。
关键细节：脉冲参数全程固定；读脉冲要小；记录环境（光照/温度）要稳定。

### 第 4 步：保持与耐久（Retention / Endurance）
- Retention：打到某个电导态，定时读，看能保持多久（视网膜应用特别关心这个）；
- Endurance：反复增强-抑制循环，看窗口会不会塌。

### 第 5 步：提取参数
从第 3 步的曲线得到：电导窗口 G_min/G_max、分辨率（扫满窗口的脉冲数）、
指数模型参数 α（步长）和 β（非线性因子，ln|ΔG| 对归一化电导作图取斜率的负值）、
非线性度 NL（对理想直线的最大偏差/窗口）、不对称比 AR（增强曲线与镜像抑制
曲线的最大偏差/窗口）、循环涨落 σ_update、读噪声 σ_read。

### 第 6 步：按应用路线使用这些参数
同样的参数，进不同的"应用引擎"（见下一节对比表）。

# 不同应用的区别（同一器件，四条路线）

| | ① 突触基础表征 | ② 仿真 NN 训练分类 | ③ 人工视网膜（本仓库） | ④ 感知预处理 + NN |
|---|---|---|---|---|
| 器件扮演的角色 | 生物突触的类比物 | **权重**（存储+乘加） | **探测器+存储器**（存图像） | 前端传感器/预处理器 |
| 是否需要训练 | 不需要 | 需要（梯度/脉冲更新） | **不需要**（模板匹配） | 后级 NN 需要训练 |
| 核心测量 | EPSC/STP/LTP/PPF | G(n)、NL、AR、噪声 | G(n)、**retention**、**uniformity** | 预处理功能的保真度 |
| 精度上限 | —（不报告精度） | 高（MNIST ~96%+） | 低（模板匹配 ~70%） | 取决于后级 NN |
| 卖点 | 仿生功能齐全 | 算力/能耗优势 | 感知即计算、超低功耗延迟 | 器件解决 NN 的痛点任务 |
| 典型风险 | 审稿人问"所以呢？" | 被问器件非理想性 | 被问精度为什么低 | 被问为什么不直接软件做 |

**② vs ③ 的取舍**（这是最能体现你理解深度的一点）：
- 路线②把器件当"可模拟的权重存储"，精度是王道，所以 NL/AR/噪声越理想越好，
  训练算法还要专门设计来对抗非理想性；
- 路线③把器件当"眼睛+大脑"，精度可以让步（人脸识别在小模板库里 70-90% 就够用），
  换来的是**零训练、零搬运**：图像信息在感知的那一刻就已经存进电导里了；
  但它对 **保持（retention）和一致性（uniformity）** 极其敏感——存的东西会变淡、
  每个像素性格不一，识别就崩。这解释了为什么原文强调 <1 V 多级调制和高均匀性阵列。
- 路线④是折中：器件只做 NN 不擅长的事（去噪、运动对比、自适应亮度等神经形态
  预处理），识别交给普通 CNN。原文同组的后续工作（如 retina-inspired
  iono-optoelectronic synapse 做"光卷积去噪+CNN 识别"）走的就是这条线。

**本仓库仿真建模的三个约定**（README 不写清楚，别人无法复现）：
1. 亮度 b∈[0,1] 量化为 round(b·n_max) 个光脉冲，电导查预计算的指数模型表；
2. **衰减只作用在测试图上**：模板是"刚感知完就注册"的新鲜状态，测试图像在等待
   比对期间衰减——若模板与图像经历相同衰减，余弦匹配对均匀衰减完全免疫，
   那就测不出保持特性的影响了；
3. 模板 = 每类注册样本存储电导图的平均（同阵列注册，像素间偏差部分抵消，
   所以一致性扫描的下降较温和）。
