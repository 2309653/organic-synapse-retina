# 人工视网膜仿真：按论文补充材料的真实方法复现（期望阈值法）

本仓库复现 **Chen et al., "Organic optoelectronic synapse based on photon-modulated
electrochemical doping", Nature Photonics 17, 629 (2023)** 补充材料（SI）中的
**人工视网膜人脸识别**应用，并整理了该论文两个应用的完整步骤。

> **勘误（重要）**：本仓库早期版本把视网膜方法理解成"模板匹配"，是**错的**。
> 通读 SI p.20-22 后确认，论文用的是**期望阈值法**（expectation-based
> thresholding）：为每个特征器件预测"目标到来时的预期光电流"，乘容差比作为
> 该器件的判决阈值，测试时统计激活率。当前代码已按真实方法重写。

论文的两个应用（同一器件，两条完全不同的技术路线）：

| | 路线 A：人工视网膜（本仓库） | 路线 B：训练神经网络（姊妹仓库） |
|---|---|---|
| 出处 | SI p.20-22 | SI p.23-25 |
| 器件角色 | 探测器 + 存储器（存图像） | 权重（差分对，存网络参数） |
| 器件模型 | 两个拟合函数（写模型+读曲面） | α·exp(−βx) 指数更新模型 |
| 是否训练网络 | **不训练** | 训练（HDBP + Adam） |
| 任务 | 二分类人脸验证 | Fashion-MNIST 分类 |

## 一、论文路线 A 的完整步骤（人工视网膜，SI p.20-22）

**第 1 步：测器件"写"模型（SI Fig. S28a）**
空白器件施加**相同时长（60 s）、不同光强**的光脉冲，记录每个光强留下的
非易失电流 → 拟合"光强 → 非易失电流增量"的**二次函数**。这是把图像亮度
写进记忆电导的物理依据。

**第 2 步：测器件"读"模型（SI Fig. S28b）**
对已训练（有记忆）的器件施加 **2 s 短光脉冲**，在多个光强下重复刺激，逐
脉冲记录"当前记忆电流"和"瞬态电流增量" → 拟合 **(光强, 记忆) → 瞬态光电流**
的函数曲面。这是预测测试时器件响应的物理依据。

**第 3 步：训练视网膜 = 写入 9 张目标人脸（SI Fig. 6a）**
- 数据：ORL 人脸库（40 人 × 10 张，64×64），选 1 个目标人（论文选了一位
  女性），9 张图用于训练；
- 每张图的灰度归一化到器件探测动态范围（论文 **2–7 mW/cm²**）；
- 逐张"照射"阵列：每个像素的光强经第 1 步的二次函数转成非易失电流增量，
  9 张图累积 → 每个器件的记忆电流。亮区（皮肤）记忆深、暗区（头发、
  眼、嘴）记忆浅——**"她长什么样"就以电导图的形式存在了阵列里**。

**第 4 步：选特征器件 + 定判决阈值（SI Fig. 6b, S28c）**
- **特征器件**：记忆电流排名前 25%（75% 分位阈值）的像素，自动圈出目标
  脸的关键区域；
- **判决阈值**：对每个特征器件，用第 2 步的曲面预测"目标的人脸再来时，
  这个器件会产生多大的瞬态光电流"（对 9 张训练图取平均），乘**容差比
  0.9**，作为该器件的激活条件。每个器件有自己的阈值——这就是
  "expectation-based thresholding"。

**第 5 步：测试与判决（SI Fig. 6c,d）**
- 测试脸（同光照归一化后）照到阵列上，每个特征器件的瞬态光电流：
  **≥ 阈值 → active（红）；< 阈值 → idle（蓝）**；
- **激活率** = active 器件占特征器件比例。论文结果：正样本（目标本人，
  不同姿态 91%、强高斯噪声 88%）**明显高于**负样本（他人，< 70%）；
- 以 ~70% 为界做二分判决。另附实用协议（SI Fig. S29）：三端器件可无损
  实时读出记忆，据此动态更新判决阈值。

**本仓库的实现对应**：`src/retina.py` 中 `write_model`/`response_model`（第
1、2 步，占位模型）、`train_retina`（第 3、4 步）、`test_activation`（第
5 步）。占位模型与论文实测拟合函数形状不同，激活率数字会不同；接入实测
器件时替换这两个函数即可。

### 复现结果（ORL 人物 #7，占位模型，容差 0.85）

| 指标 | 本仓库 | 论文 |
|---|---|---|
| 正样本激活率（干净） | **95%** | 88–91% |
| 正样本激活率（高斯噪声 σ=0.1） | 73% | 88% |
| 负样本激活率（mean / 最难个体） | 35% / 86% | < 70% |
| 70% 界二分：正通过 / 负拒绝 | 100% / 97% | — |

非理想因素扫描（`figures/fig2_retina_sweep.png`）：
- **记忆衰减（保持特性）是命门**：衰减 20% 正样本激活率就从 95% 崩到
  27%——所以器件必须"存得住"；
- **像素间一致性**：±5% 无感，±10% 开始掉，±30% 掉到 71%；
- **读噪声**：σ=0.05 即明显伤害（79%）；
- **容差比**：存在最优点（本模型 0.85；论文器件取 0.9）——太松负样本
  混入，太紧正样本误杀。

### 方法适用边界（诚实对照）

MNIST 十分类（`--task mnist`，每类一个视网膜取激活率 argmax）只有
**~40%**，远低于训练型 MLP 的 96%（姊妹仓库）。原因：该方法为**刚性
目标的身份验证**设计（同一张脸的 9 张图差异小、记忆图锐利），而手写
数字笔迹变化剧烈、类内记忆图弥散。这正是论文选人脸做该应用的原因。

## 二、论文路线 B 的完整步骤（训练网络，SI p.23-25）

**第 1 步：测增强/抑制脉冲串并拟合指数模型（SI Fig. S31）**
- 增强：光脉冲（论文器件 7.0 mW/cm²、脉宽 0.04 s、间隔 0.04 s，SI Fig. S8）；
- 抑制：反向**电压**脉冲（0.4 V、0.1 s、间隔 8 s）；
- 各扫出 60 个可分辨权重态的 G(n) 曲线，拟合更新模型（α=步长、β=非线性）：

```
ΔG = G(n+1) − G(n) = +α·exp[−β·(G(n)−G_min)/(G_max−G_min)]   增强
                    −α·exp[−β·(G_max−G(n))/(G_max−G_min)]   抑制
```

**第 2 步：差分对映射权重**
一个突触权重 W = G⁺ − G⁻（两个器件），正负权重都可表示。

**第 3 步：搭网络（Fashion-MNIST）**
- 感知机：785 输入（28×28+偏置）× 10 输出 softmax，共 7850 突触；
- LeNet CNN：3 卷积层（5×5：1→6→16→120）+ 2 池化 + 2 全连（120×84、
  84×10）+ softmax，共 61,706 突触。
- 前向：I = W·V（全连）或 I = W∗V（卷积），V = f(I)。

**第 4 步：HDBP 训练（hardware-based backpropagation）**
- 主机算梯度：交叉熵损失 + **Adam** 优化器 → 每个权重的期望更新 ΔW；
- 器件执行更新（SI eq.1-2）：ΔW>0 → G⁺ 增强、G⁻ 抑制；ΔW<0 → 反之；
  每个器件按第 1 步拟合的指数模型逐脉冲更新；
- 饱和处理：任一器件触到 G_max/G_min 时，把这对器件重置回 G_min（避免
  差分对一侧饱和后无法表示该方向权重，论文称 "avoid the scale issue"）。

**第 5 步：结果**
每 epoch 用 60000 张训练、10000 张测试，25 epoch 内收敛：
- 感知机 **69.0%**；LeNet CNN **89.5%**（Fashion-MNIST）；
- 可视化：感知机的权重图随训练逐渐显出商品轮廓；CNN 用 Grad-CAM 看
  关注区域从整体移向商品边缘。

**与姊妹仓库的关系**：[organic-synapse-mnist](https://github.com/2309653/organic-synapse-mnist)
实现的就是这条路线（MNIST 784-100-10，器件仿真 96.26%）。其抑制分支写法
`−α_d·exp[+|β_d|·x]` 与论文 eq.2 抑制分支 `−α·exp[−β(G_max−G)/R]` 在
α 重标定下**数学等价**（令 |β_d|=β、α_d=α·e^(−β) 即可互转）。

## 三、通用器件测试步骤（论文实际测了什么）

按论文 SI 的实验顺序整理，测完 1–4 可同时支撑两条应用路线：

1. **基本电学**：转移/输出特性、循环稳定性（SI Fig. S3）；
2. **单脉冲光响应**：变光强（S11）、变波长（S12）、变栅压（S15）、变
   漏压（S16）下的 EPSC——确定读出协议与工作点；
3. **塑性**：短/长时程可塑性、连续光脉冲增强 + 反向电压脉冲抑制
   （SI Fig. S8，即路线 B 的 G(n) 测量）；
4. **多级态与重复性**：3 循环内每个电导态的区分度（线性区 0–15 µA、
   态间涨落 ~0.1 µA，SI Fig. S7）；60 个权重态拟合 α/β（S31）；
5. **保持与耐久**：60 s 光脉冲后的记忆保持（S17）、10,000 次开关循环
   （S10）、环境存放一周（S9）；
6. **阵列验证**：4×5 阵列、两种光强选择性照射（S26）；
7. **面向视网膜应用的两个函数**：光强→非易失电流（S28a，60 s 脉冲）、
   (光强,记忆)→瞬态电流曲面（S28b，2 s 脉冲）。

## 四、运行

```bash
pip install -r requirements.txt

# ORL 数据（约 1.2 MB，一次性）
git clone --depth 1 https://github.com/lloydmeta/Olivetti-PNG.git data/ORL

python src/retina.py                 # 主实验：ORL 人脸验证 + 流程图
python src/retina.py --sweep         # 非理想因素扫描（衰减/一致性/噪声/容差）
python src/retina.py --target 20     # 换一个目标人物（0-39）
python src/retina.py --task mnist    # MNIST 对照（方法适用边界）
```

常用参数：`--target`（目标人）、`--tolerance`（容差比）、`--decay`
（记忆衰减）、`--cell-variation`（像素间差异）、`--read-noise`（读噪声）、
`--n-levels`（光强量化档数）、`--noise-sigma`（正样本噪声强度）、
`--feature-quantile`（特征分位，论文 0.75）。

## 局限与替换实测数据的方法

- `write_model` / `response_model` 是**占位模型**（凸二次写入 + 阈值/平方
  增益读出，经消融实验选定，兼顾区分度与噪声鲁棒性）。论文用的是自己的
  实测拟合（系数在付费版 SI 图内，原始数据可向作者索取或按第三节第 7 条
  自测）；
- 接入实测：按 SI Fig. S28 的两个实验测出自己的函数，直接替换
  `retina.py` 顶部这两个函数，其余算法不动；
- 负样本长尾（最难个体 86%）高于论文的 "<70%"——论文测试的负样本数量
  少，我们的 390 张全量测试包含了长相相似的个例；换实测器件模型后该
  数字会变。
